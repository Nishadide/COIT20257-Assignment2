# keys

The four serialized key files generated by `Security.KeyGenerator`:

    EdgePri.ser      EdgePub.ser
    DevicesPri.ser   DevicesPub.ser

These are excluded from git by `.gitignore`, because each team member
regenerates them locally. If the team decides to commit them instead (so
everyone shares one key set), remove the `keys/*.ser` line from `.gitignore`.

## Which file goes where at runtime

    EdgeLayer/     EdgePri.ser     EdgePub.ser     DevicesPub.ser
    DeviceLayer/   DevicesPri.ser  DevicesPub.ser  EdgePub.ser

Each layer holds its OWN private key and the OTHER layer's public key.
Private keys are never copied between the two folders — that is the
assumption the assignment's authentication protocol relies on.
